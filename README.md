# CSE420 – Compiler Design Lab

This repository contains the laboratory works and practice files for **CSE420 – Compiler Design**. The repository is organized into different lab parts, with each part focusing on an important concept or phase of compiler design.

##  Lab Contents

Each lab covers a specific topic related to compiler construction, including:

* **Lexical Analysis** – Tokenization, regular expressions, and lexical analyzers.
* **Syntax Analysis** – Context-free grammars, parsing techniques, and syntax trees.
* **Semantic Analysis** – Type checking, symbol tables, and semantic rules.
* **Intermediate Code Generation** – Three-address code, syntax-directed translation, and intermediate representations.
* **Code Optimization** – DAGs, basic blocks, control-flow graphs, and optimization techniques.
* **Code Generation** – Target code generation and related compiler techniques.
